# Agent Ladder Marketplace

这是 Agent Ladder 的 Codex 插件市场仓库。

在 Codex 的“添加插件市场”窗口中填写：

- 来源：`https://github.com/513975/agent-ladder`
- Git 引用：留空，使用默认分支 `main`
- 稀疏路径：留空

添加市场后，在 Agent Ladder 市场中安装 `agent-ladder` 插件，并新建一个任务使 Skill 生效。

插件的完整说明位于 [`plugins/agent-ladder/README.md`](plugins/agent-ladder/README.md)。
